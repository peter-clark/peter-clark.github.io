{% comment %} ============================================================ BUTTON GRID — a grid of buttons, N columns across. The grid ONLY. It carries no frame of its own: it is meant to sit in a box that already has one, which on the centre column means a menubox (see centre-panel.html). Giving it a second border inside that box was the earlier mistake. USAGE Normally you do not call this directly — put a `panels:` entry in a page's front matter and centre-panel.html calls it. Call it by hand only to drop a grid into the middle of page copy: {% include button-grid.html items=site.data.simulations cols=3 %} {% include button-grid.html posts=6 cols=2 %} NOTE: Liquid runs before the page is parsed as HTML, so an include left inside an HTML comment still renders. Wrap commented-out examples in a raw block. PARAMETERS items a list of entries. Each needs a label under `title` or `name`, and a destination under `link` or `url`. Used only when `items` is absent. cols columns across. Default 3. Read from a custom property, so a new column count needs no CSS change. limit cap on how many of `items` to show. Default: all. title optional small heading above the grid. Usually left off — the box's own title does that job. empty text shown when there is nothing to list. Styling is _sass/components/button-grid.scss.
